# Phase 14 · Learning loop

## 14a · After a session went wrong

```
In this session an agent <what went wrong, in one or two sentences>. Decide whether a rule was
missing or was ignored. Read AGENTS.md (Project Learnings), CLAUDE.md §0 and the constitution.
- Missing: propose one rule, written concretely ("Always X for Y", with the command or path), and
  where it goes: AGENTS.md Project Learnings (general), CLAUDE.md §0 (a project trap: symptom, cause,
  fix), or the constitution (a principle; needs a version bump).
- Ignored: propose how to make the existing rule harder to miss (shorter, earlier, repeated in the
  SESSIONS.md guard text).
- If it is generic, also propose the change to the delivery framework (template, prompt or
  a PILOT.md failure mode), and a line for its examples/ case study.
Show the exact diff. Apply nothing until the owner agrees.
```

## 14b · Prune (at every wave close)

```
Prune AGENTS.md and CLAUDE.md. For each line, ask: would removing this cause an agent to make a
mistake? Propose deleting the lines that would not, merging duplicates, and moving reference
material out of CLAUDE.md into docs/AGENTS.md. Targets: AGENTS.md about 100 lines of project content
and under 300 in total; CLAUDE.md under about 150. Show the diff and the line counts before and
after. Apply nothing until the owner agrees.
```
